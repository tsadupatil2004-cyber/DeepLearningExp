# Multilayer Neural Network

## AIM

To study and understand the working of a **Multilayer Neural Network (MLP)** and its use in solving classification problems.

---

## THEORY

A **Multilayer Neural Network** is an artificial neural network that contains an **input layer, one or more hidden layers, and an output layer**.

```text
Input Layer → Hidden Layer → Output Layer
```

Each neuron receives inputs, applies weights and bias, and passes the result through an activation function.

The weighted sum is calculated as:

```text
Z = W1X1 ​+ W2​X2 ​+ ... + Wn​Xn ​+ b
```

---

### Forward Propagation

In forward propagation, input data moves from the input layer through the hidden layers to the output layer to generate a prediction.

---

### Backpropagation

Backpropagation calculates the error between the actual and predicted output and updates the weights and biases to improve the model.

---

### Common Activation Functions

- **ReLU** – Commonly used in hidden layers.
- **Sigmoid** – Commonly used for binary classification.
- **Softmax** – Commonly used for multi-class classification.

---

### Advantages

- Can learn complex and non-linear patterns.
- Can solve problems that a single-layer perceptron cannot.
- Useful for classification and regression.
- Forms the foundation of Deep Learning.

---

### Applications

- Image Classification
- Speech Recognition
- Pattern Recognition
- Fraud Detection
- Medical Diagnosis
- Natural Language Processing

---

### CONCLUSION

A Multilayer Neural Network consists of multiple layers of neurons and uses forward propagation and backpropagation to learn from data. It can learn complex and non-linear relationships and is an important foundation of Artificial Neural Networks and Deep Learning.
